# Arta — Coming Soon

صفحه‌ی «به‌زودی» آرتا با تایمر معکوس تا **جمعه ۱۷ میزان ۱۴۰۵ (۹ اکتبر ۲۰۲۶)، ساعت ۱۲:۰۰ ظهر به وقت کابل**.
کاملاً استاتیک (HTML/CSS/JS خالص، بدون build) و آماده‌ی GitHub Pages.

## فایل‌ها

| فایل | کار |
|------|-----|
| `index.html` | ساختار صفحه |
| `style.css` | طراحی، انیمیشن‌ها، ریسپانسیو |
| `script.js` | تایمر، دو زبانه (فارسی/انگلیسی)، واتساپ، تعامل‌ها |
| `404.html` | برگرداندن آدرس‌های اشتباه به صفحه‌ی اصلی |

## تنظیمات

همه‌ی تنظیمات بالای فایل `script.js` در `CONFIG` است:

```js
launch:    '2026-10-09T12:00:00+04:30', // لحظه‌ی افتتاح (با منطقه‌ی زمانی کابل)
announced: '2026-09-29T00:00:00+04:30', // شروع شمارش — برای نوار «مسیر تا افتتاح»
whatsapp:  '93728000690',               // شماره واتساپ با کد کشور، بدون + و صفر
launchUrl: '',                          // اختیاری: بعد از افتتاح به این آدرس برود
```

متن‌ها (فارسی و انگلیسی، و پیام آماده‌ی واتساپ) در `STRINGS` همان فایل هستند.

## تست

- `?lang=en` یا `?lang=fa`: باز کردن مستقیم با یک زبان
- `?launch=+10`: شبیه‌سازی افتتاح ۱۰ ثانیه بعد
